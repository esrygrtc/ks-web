The product

run

Point any agent at KeepState. Same models, same code.

ks run --image claude-code

checkpoint

Filesystem + model memory + tool state. One atomic snapshot.

ks save s_7f3a

fork

Branch step 40 into six universes. Keep the winner.

ks fork s_7f3a@40 -n 6

resume

Warm resume under 100 ms. Cold under 90 s. On any provider.

ks wake s_7f3a

replay

Re-execute what actually happened. Evidence, not logs.

ks replay s_7f3a
